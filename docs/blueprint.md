# **App Name**: VyaparOS Nepal

## Core Features:

- Multi-tenant Management: Support multiple tenants (businesses) with subdomain routing and isolated data.
- Inventory Management: Manage product inventory, including name, variant, price (NPR), stock level, and low stock alerts.
- Order Management: Create and manage orders, track payment methods (eSewa, Khalti, FonePay, Udhaari), and order statuses.
- AI-Powered Business Responses: Generate context-aware, helpful responses in 'Romanch' for Nepali businesses using local Ollama Mistral instance. Employs a tool to identify date contexts, e.g. public holidays
- Real-time Chat Module: Enable real-time chat with customers, including AI-suggested replies based on conversation context.
- Udhaari (Credit) Ledger: Implement a specialized ledger to track and manage credit (Udhaari) transactions.
- Localized UI and Formatting: Support Nepali language, NPR currency formatting, and Nepal-specific address schema.

## Style Guidelines:

- Primary color: Deep Indigo (#3F51B5) to convey trust and stability, appropriate for business operations.
- Background color: Very light Indigo (#F0F2F9), close in hue to the primary but highly desaturated for a calm backdrop.
- Accent color: Slate Blue (#607D8B) as a neutral, professional shade analogous to Indigo to give UI hints.
- Body and headline font: 'Inter', sans-serif, with a modern, objective look.
- Use consistent, modern icons from a library like Font Awesome or Heroicons, customized with primary color.
- Employ a sidebar layout for main navigation and a CMD+K command center for quick actions.
- Use subtle Framer Motion animations for transitions and interactions to enhance user experience.
